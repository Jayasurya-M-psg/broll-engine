IncuBrix Engineering Assessment 3 — Technical Report
Candidate: Jayasurya M · Complete Architecture & Metrics

🎯 Problem Statement

A creator records a voiceover and needs to match B-roll footage to every sentence — frame-accurate, licence-clean, with subtitles. Manual search takes hours. This engine automates the full pipeline in under 60 seconds.

🏗️ 10-Step Autonomous Pipeline Architecture

  1. Input Processing: Accepts plain-text scripts or audio voiceover URLs.
  2. Neural TTS: Synthesizes speech using Microsoft Edge TTS neural voices with customizable cadence.
  3. Whisper ASR: OpenAI Whisper produces frame-accurate sentence & word-level timestamps.
  4. Scene Segmentation: Splits sentences into distinct visual beats without dead air gaps.
  5. Query Extraction: KeyBERT semantic keyphrase extraction with spaCy noun-chunk fallback.
  6. Multi-Source Footage: Pexels API + Pixabay API search with keyword filtering and deduplication.
  7. CLIP Vision-Language Scoring: OpenAI CLIP (ViT-B/32) computes cosine similarity for each visual clip.
  8. Deduplication & Safety: Enforces zero clip repetition across the video; applies safety filters.
  9. FFmpeg Scene Assembly: Normalizes color, trims, scales/pads without black bars, burns synced subtitles, and mixes background music.
  10. Multi-Ratio Rendering: Exports in 16:9 Landscape (YouTube), 9:16 Portrait (TikTok/Reels), and 1:1 Square (Instagram).
